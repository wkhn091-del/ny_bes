# מפת תנועה

כל אנימציה משתמשת בטוקנים מ-`src/app/globals.css`. בלי ערכים קשיחים.

| טוקן | ערך | שימוש |
|------|-----|-------|
| `--dur-micro` | 160ms | משוב לחיצה, hover, מעבר צבע. ברירת המחדל של `transition` |
| `--dur-base` | 420ms | מספר מתגלגל, מגירות, פס הזמנה במובייל |
| `--dur-reveal` | 900ms | ציור קו, זום תמונה ב-hover, פיצוץ נקודות |
| `--ease-out` | cubic-bezier(0.22, 1, 0.36, 1) | כניסות ומשוב |
| `--ease-in-out` | cubic-bezier(0.65, 0, 0.35, 1) | תנועת מצלמה במפה |
| `--stagger` | 60ms | מדרג בין פריטים |
| `--delay-check/burst/rise` | 520/600/700ms | רצף רגע האישור |

| רגע | מה זז | למה (לפי הספר) | Reduced motion |
|-----|-------|-----------------|----------------|
| כותרת ראשית | בלי תנועה. לא נכנסת עם opacity (LCP) | — | — |
| משרד בתלת־ממד (`/office`) | הליכת מצלמה דרך הדלת בכניסה וביציאה, שמש מהחלון שזזה לאט, אבק בקרן האור | תחושה של להיכנס לחדר אמיתי | קפיצה ישירה פנימה/החוצה בלי הליכה; בלי 3D: תמונה קבועה |
| סיור בבניין (`/building`) | מגדל משרדים בתלת־ממד בתוך עיר עם בלוקים של ניו יורק; השמיים, השמש, הירח והחלונות המוארים עוקבים אחרי השעה בישראל (או "יום"/"לילה" ידני, במעבר הדרגתי); מוזיקת רקע מסונתזת רק אחרי לחיצה על כפתור, ומחליפה אווירה בין יום ללילה; בקומה הפתוחה רהיטים אמיתיים ותמונות החללים על המסכים ובגלריה; בחירת קומה מעיפה את המצלמה, הקומות שמעליה נחתכות ונחשף ריהוט אמיתי; "להיכנס לקומה" מחליק פנימה דרך החזית להליכה בגובה העיניים (גרירה להסתכל, לחיצה על הרצפה או WASD ללכת), והמעלית מחליפה קומה בהחשכה קצרה; "להיכנס לבניין מהרחוב" מנמיך את המצלמה מעל השדרה בלבד (בלי לחצות בניינים) לרחוב, חוצים במעבר חצייה (המכוניות עוצרות), הדלתות נפתחות, ובמעלית בלובי בוחרים קומה | מעבר מצלמה רך, חזית שנמחקת, תאורת תקרה שנדלקת בגלים, עמודי אור שפועמים לכיוון הדלת, דלתות הזזה, קיר LED | בלי 3D או עם הפחתת תנועה: תמונת פוסטר סטטית ובחירת קומות כרגיל |
| מפה תלת־ממדית | כניסה, מעוף מצלמה לחדר בלחיצה, הטיה עדינה לפי העכבר | מוכיח שהזמינות אמיתית ("רואים מה פנוי") | מפה דו־ממדית |
| גלילה | `.reveal`, צמוד לגלילה ולא לזמן | חשיפה הדרגתית בלי עיכוב קריאה | ללא |
| כפתורים | `active:scale-[0.97]` | משוב מיידי ללחיצה | ללא שינוי (זה לא תנועה מתמשכת) |
| סכום הזמנה | מספר מתגלגל | מראה שהמחיר מחושב מול העיניים | קפיצה ישירה לערך |
| דף תודה | עיגול וסימן וי מצוירים, פיצוץ נקודות, פרטים עולים במדרג | רגע שיא אחרי תשלום | סטטי |

כלל: אין `transition-all`. מציינים מאפיינים (`transition-[transform,border-color]`).
