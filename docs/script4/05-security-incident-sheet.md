# SpaceHub — דף אבטחה ואירועים (לתלות ליד המחשב)

## ממה האתר מוגן

- **פרטי אשראי** — לא נוגעים בהם בכלל. התשלום מתבצע אצל Stripe, כולל אימות 3D Secure.
- **שינוי מחירים מהדפדפן** — בלתי אפשרי. כל מחיר מחושב מחדש בשרת מול המחירון.
- **גישה להזמנה של מישהו אחר** — כל לקוח רואה רק את ההזמנות שלו (נבדק בשרת ובמסד הנתונים).
- **ניחוש קודים ובוטים** — הגבלת ניסיונות, Cloudflare Turnstile, וקוד כניסה חד-פעמי במקום סיסמה.
- **הזרקת קוד לאתר (XSS)** — מדיניות CSP מחמירה, תוכן משתמשים מוצג כטקסט בלבד.
- **הזמנה כפולה של אותו חדר** — חסומה ברמת מסד הנתונים.

## מה באחריותכם

1. **2FA** בכל חשבון: Google/GitHub (כניסה ל-Studio), Stripe, רשם הדומיין, Vercel.
2. **הרשאות מינימום** — עורך תוכן לא צריך גישה ל-Stripe. מנהל סניף רואה רק את הסניף שלו.
3. **עזיבת עובד** — מסירים את כל הגישות שלו באותו יום, ומודיעים לנו.
4. **לא משתפים** סיסמאות, קודי אימות או טוקנים. אף פעם. גם לא איתנו.

## אירוע אבטחה או באג רגיל?

| אירוע אבטחה 🚨 — פונים מיד | באג רגיל 🐞 — פנייה רגילה |
|---|---|
| התחברות לא מוכרת ל-Studio / Stripe / Vercel | כפתור לא עובד, טקסט שגוי |
| שינוי מחיר או תוכן שאף אחד מהצוות לא עשה | מייל אישור שהגיע באיחור |
| מייל "דחוף" שמבקש סיסמה, קוד או העברת כסף | תמונה שלא נטענת |
| לקוחות מדווחים על חיובים שלא ביצעו | עמוד שנטען לאט |
| החזרים כספיים שלא אישרתם | בעיית תצוגה בטלפון מסוים |
| מחשב של עובד עם גישה נגנב או נפרץ | |

## חושדים בפריצה — 4 צעדים, בסדר הזה

1. **מנתקים** — מסירים את המשתמש החשוד מ-Sanity / Vercel / Stripe, ומחליפים את הסיסמה של החשבון שנפגע. ב-Stripe: Settings → Team.
2. **מתקשרים אלינו מיד** — [טלפון חירום — ממתין לך]. לא מחכים למייל.
3. **לא מוחקים כלום** — לא לוגים, לא מיילים חשודים. הם הראיות.
4. **אנחנו מסובבים מפתחות** — מחליפים את כל הסודות של האתר (Stripe, מסד נתונים, webhooks), בודקים לוגים ומדווחים לכם בכתב מה קרה.

> אם נחשף מידע אישי של לקוחות — ייתכן שחלה חובת דיווח לרשות להגנת הפרטיות. נלווה אתכם בזה.
